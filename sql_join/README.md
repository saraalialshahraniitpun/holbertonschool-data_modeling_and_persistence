# SQL - Joins

This directory contains SQL scripts demonstrating relational joins (INNER JOIN, LEFT JOIN) across multiple tables, handling one-to-many and many-to-many relationships.

- **1-books-with-authors.sql**: Retrieves books with their corresponding authors using INNER JOIN.
- **2-authors-with-books.sql**: Lists all authors and their books (including authors with no books as NULL) using LEFT JOIN.
- **3-students-and-courses.sql**: Lists students and their enrolled courses using INNER JOIN (many-to-many).
- **4-courses-and-students.sql**: Lists all courses and their students (including courses with no students as NULL) using LEFT JOIN.
